# Scope

Train the original Phase 1 complaint classifier locally or in a SageMaker training job, then deploy it on a SageMaker AI real-time CPU endpoint. Run the Signal → Insight → Action loop from a CLI using synthetic fixtures. The endpoint runs the fitted text preprocessing and classifier together. Routing decisions are simulated. The optional [guardrails lab](../docs/guardrails.md) covers a guarded endpoint update and a Bedrock content check before invoking SageMaker. See the [guardrails contract](06-guardrails.md) for the acceptance criteria.

The managed path uses one shared CPU training job and one serving instance in a teaching sandbox. The [architecture](../docs/architecture/README.md) and [managed training contract](05-managed-training.md) describe the artifact handoff. The optional [registered-release flow](07-registry-release.md) demonstrates the package approval gate and manual deployment through GitHub Actions. The MLOps delivery diagram also covers production steps beyond the lab. EventBridge, DynamoDB, automated retraining, and automated monitoring jobs are future extensions.
