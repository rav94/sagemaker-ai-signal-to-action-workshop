# Scope

Train and evaluate the Phase 1 complaint classifier with a native SageMaker Pipeline, register a passing candidate, and promote the manually approved package to a SageMaker AI real-time CPU endpoint. The local path trains and packages the classifier with `uv`, serves it over loopback HTTP, and applies the same routing policy as the AWS demo. See the [local lab](../README.md#run-the-local-lab). Run the Signal → Insight → Action loop from a CLI using synthetic fixtures. The endpoint runs the fitted text preprocessing and classifier together. Routing decisions are simulated.

The AWS path uses the workshop Studio domain, one shared SageMaker pipeline, and one steady-state serving instance in a teaching sandbox. The rollout briefly provisions a second fleet. The [registered-release flow](07-registry-release.md) covers managed training, held-out evaluation, conditional registration, and manual promotion through GitHub Actions. The GitHub IAM setup configures the shared provider and then deploys the workshop IAM roles. An optional [content screening exercise](06-guardrails.md) reuses the guardrail owned by the Bedrock workshop before invoking the deployed classifier. The same GitHub workflow demonstrates [blue/green rollback](07-registry-release.md#rollback-drill) using a second approved package. The [architecture](../docs/architecture/README.md) and [managed training contract](05-managed-training.md) describe the artifact handoff. The [production MLOps notes](../docs/mlops.md) cover staging, canaries, and ongoing quality checks. EventBridge, DynamoDB, automated retraining, and automated monitoring jobs are future extensions.
